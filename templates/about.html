ABOUT GRABIT

File sharing, made simple.

Grabit is built around one idea: sharing a file should not feel complicated.

What is Grabit?

Grabit is a code-based file-sharing platform. A sender uploads a document and receives a unique code. The sender shares that code with the intended recipient, who can enter it on Grabit and download the file.

How the current system works

Your Flask backend stores uploaded files in the uploads folder and keeps their code, filename, and expiry information in SQLite. The receiver uses the code to retrieve the available files through the API.

Built to grow

The frontend is separated from the Flask API, so you can later add authentication, cloud storage, stronger security controls, file-size limits, and other features without rebuilding the whole interface.
